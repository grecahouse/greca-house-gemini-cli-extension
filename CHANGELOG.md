# Changelog

## 1.1.0 (2026-10-04)

- First public release. Connects Gemini CLI to the Greca House MCP server at
  https://grecahouse.com/mcp (server version 1.1.0, five read-only tools).
- Context: exact bedroom counts with `min_bedrooms` and `max_bedrooms`, the Golden
  Visa classification filter and its applicant boundary, dated research, and
  buying-cost assumptions.
- Golden Visa replies name the property-only classification, the eligibility and
  compliance boundary and the check with a qualified Greek lawyer.

The extension version follows the server: a new or renamed tool is a minor
version, a wording change is a patch.
